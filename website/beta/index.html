TEST GUIDE

测试说明

本轮面向获邀的 iPhone 用户。请重点留意以下路径是否顺畅、文案是否清楚，以及异常后能否安全返回。

建议重点体验

  1. 完成一次城市打卡，在足迹地图和城市档案中查看记录。
  2. 创建或编辑一本旅行册，尝试贴纸、相框、背景与照片排版。
  3. 使用测试 NFC 纪念品完成碰触、打开礼品、登录或受邀查看流程。
  4. 退出并重新打开 App，确认本地内容和当前状态符合预期。
