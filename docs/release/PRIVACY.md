# OneTapReality 隐私与数据说明

生效日期：2026-08-24。适用于 OneTapReality 1.1.2 外部 TestFlight Beta 及其后续版本。隐私支持：`support@onetapreality.com`。

## 本地旅行册

本地草稿默认保存在此设备；只有你主动发布礼品时，所选内容才会上传给受邀成员。未登录时，你可以在 `guest` 本地库创建、编辑、删除、恢复和导出旅行册。登录后，本地库按规范化邮箱隔离；首次登录由你明确选择继续使用 guest 库或将 guest 库迁移到当前账号，应用不会静默迁移，也不会让另一个账号读取该库。

旅行册初稿由本地规则生成，可继续编辑；生成器不分析照片内容，不识别人脸、地点或图像中的物体。照片原件仍由系统相册管理。PDF 导出由你主动发起，一次只处理一本旅行册。

## 登录与受邀共享

登录和礼品访问使用邮箱验证码。我们处理规范化邮箱、内部 User ID、一次性验证码的加密学哈希、会话、礼品成员关系、邀请状态和必要的安全记录。会话最长 30 天，退出、账号删除或安全撤销会提前使其失效；验证码短时有效且仅能使用一次。

只有你主动发布礼品时，选中的共享快照、文字、排版和照片副本才会上传。owner 或已激活的 editor 只有在显式发布云端版本时才会传输所选内容；应用不会自动上传或修改设备上的本地原件。礼品只有受邀成员可访问：owner 管理礼品，viewer 只读，editor 可编辑共享版本。邀请资格不直接公开内容，受邀者必须用匹配邀请邮箱的账号完成首次 NFC 激活。实体卡只保存 HTTPS 礼品链接；应用不读取、保存或上传 NFC UID，也不写入用户扫描的卡片。

受邀成员可以举报当前共享快照、屏蔽邀请者或成员，并主动退出礼品。举报后内容立即对举报者隐藏；屏蔽会移除双方关系并阻止再次邀请。举报原因、处置状态和最少量支持记录只用于安全处置，不用于公开资料、广告或画像。需要协助时联系 `support@onetapreality.com`。

## 我们使用的服务

- Railway 托管 OneTapReality API；Railway PostgreSQL 保存账号、会话、礼品、邀请、成员、共享元数据、举报/屏蔽状态和删除任务。
- Cloudflare R2 保存用户主动发布到礼品的私有照片副本与共享快照媒体；对象不公开列出，访问由服务端授权。
- Resend 发送邮箱登录、邀请、删除验证和必要的支持通知。

这些服务作为应用功能处理数据。OneTapReality 不出售数据，不进行跨 App 或网站跟踪，不用于跟踪，不投放广告，也不接入分析 SDK。Tracking = No。

## 保存期限

- 设备本地内容保存到你在 App 内删除、清除应用数据或卸载应用为止。
- 验证码在使用或到期后进入清理；会话在退出、撤销、到期或账号删除时失效。
- 礼品共享内容和成员关系保存到拥有者停用礼品、相关内容被处置或账号被删除为止。访问撤销先于异步媒体清理；临时清理失败会自动重试。
- 举报、屏蔽和支持处置记录只在保障受邀共享安全、处理争议及履行适用义务所需期间保留；账号删除时删除可识别审计数据，依法必须保留的最小记录会与账号内容分离。

## 删除本机数据与永久删除账号

应用提供两个不同入口：

1. “删除本机旅行册”只删除当前选中的本地库及其本机照片副本，不影响其他账号库，也不会自动删除云端账号；当前选择账号库时不删除独立 guest 库。
2. “永久删除账号及云端数据”在 App 内完成邮箱挑战验证。提交后全部会话立即撤销，并返回删除回执和最迟完成时间。

账号删除任务会在 24 小时内永久停用该账号拥有的礼品，并删除共享快照、Cloudflare R2 照片媒体、邀请、成员关系、管理请求、验证码、账号及可识别审计数据。失败任务会重试并通知支持人员。删除当前账号对应的本地库时，独立 guest 库仍保留。若超过回执显示的完成时间，请把回执编号发送至 `support@onetapreality.com`；不要发送验证码或礼品链接。

成员被移除、权限撤销、礼品停用或账号进入删除流程后，访问和共享快照会立即撤销。私有 R2 媒体由受保护的维护任务异步删除；删除失败时继续重试，且不会恢复已撤销的访问。

## 权限与控制

照片选择直接使用 iOS 系统选择器，不预先申请完整照片库访问；仅在你明确保存导出结果时申请 add-only/write-only 权限。App 内 NFC 扫描只读取当前环境的 NDEF HTTPS 礼品 URL。拒绝照片或 NFC 权限不会阻止浏览和编辑已有的本地旅行册。

你可以在 App 内查看、退出或管理礼品关系，举报或屏蔽受邀成员，删除当前本地库，以及永久删除账号。隐私、删除或安全问题请联系 `support@onetapreality.com`。
