# 隐私说明

生效日期：2026-07-30。适用于 OneTapReality TestFlight、Development Build 与生产版。

本地旅行册、照片 URI、文字和编辑布局默认保存在当前设备，生成器不读取图像内容。owner 或已激活的 editor 登录并显式发布云端版本后，该版本的共享快照及所选照片副本才会上传到私有 Cloudflare R2。获邀者必须使用匹配邀请邮箱的账号完成首次 NFC 激活，之后才可读取完整相册。发布不会自动上传或修改设备上的本地原件。

应用内“删除所有数据”只删除设备本地内容；礼品停用后，访问和共享快照会立即撤销。私有 R2 媒体由受保护的维护任务异步删除，删除失败时继续重试，不影响访问已被撤销的结果。

礼品访问使用邮箱验证码建立 30 天会话。我们保存规范化邮箱、验证码/会话的加 pepper 哈希、礼品成员关系和礼品发布元数据；验证码一次性且短时有效。标签本身只含 HTTPS URL，不采集 NFC 芯片 UID。

每件礼品只能有一位 owner 及最多两位受邀成员。owner 邀请时可选择 viewer 或 editor，并可随时切换权限。两者都须以匹配邮箱的账号完成首次 NFC 激活，之后才能查看完整相册预览。viewer 只读；editor 可使用完整 Canvas 直接发布云端共享快照的新版本，但只修改云端共享快照，不修改任何设备上的本地原件。本地原件不会自动上传。

editor 若申请整册删除、移除成员或修改权限，必须等待 owner 批准；owner 可直接管理。成员被移除、权限被撤销、礼品停用或停测后，服务端立即拒绝读取及未完成提交。已有媒体引用由服务端验证，新媒体先进入当前环境的私有 R2 临时对象，校验后提升为不可变对象。staging 与 production 数据严格隔离。本功能不引入第三方服务、支付或分析。

拥有者永久停用礼品时，访问名单和共享快照会立即撤销；媒体删除若临时失败，会由受保护的服务端维护任务重试。请通过 `support@onetapreality.com` 联系隐私支持。

## 2026-08-16 本地账号隔离与礼品激活补充

- 本地旅行册、草稿、回收站记录和沙盒照片按已验证邮箱的规范化值（去除首尾空格并转小写）绑定。未登录时不会读取、创建、编辑或删除这些内容；切换账号后，另一个账号的本地内容按不存在处理。
- 升级仍使用 `luyi.db`、同一 iOS Bundle ID 和 Android package，因此只要操作系统保留同一应用沙盒，本地内容不会因 Alpha、Beta、Production 构建更新或 API origin 切换而丢失。卸载、换设备或更换应用标识不在此保证范围内。
- 本地原件不会自动上传或被云端发布修改。owner 或已激活的 editor 只有在显式发布云端版本时，才会把该版本选中的媒体副本送入当前环境的私有 R2；staging 与 production 的数据库和 R2 严格隔离。
- 邀请邮箱只建立 viewer 或 editor 激活资格，不直接公开相册。受邀者必须登录匹配邀请邮箱的账号并通过礼品高熵链接完成首次 NFC 激活，之后才会在“我的纪念品”中看到共享快照。成员被移除、礼品停用或停测开关开启后将无法读取；移除后重新邀请需要重新激活。
- 礼品链接是持有证明。系统不保存客户端 token，也不采集 NFC UID；同一链接被转发时，服务端无法判断它是否来自实体碰卡。
