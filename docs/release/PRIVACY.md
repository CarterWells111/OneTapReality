# 隐私说明

生效日期：2026-07-30。适用于 OneTapReality TestFlight、Development Build 与生产版。

本地旅行册、照片 URI、文字和编辑布局默认保存在当前设备，生成器不读取图像内容。只有礼品拥有者登录并明确点击“发布共享相册”后，所选照片副本及相册快照才会上传到私有 Cloudflare R2，供该礼品的获邀邮箱读取。日常编辑不会自动上传或同步。

应用内“删除所有数据”只删除设备本地内容；已发布礼品的共享快照和媒体需由礼品管理者在礼品管理流程中停用，停用会删除共享快照和媒体。

礼品访问使用邮箱验证码建立 30 天会话。我们保存规范化邮箱、验证码/会话的加 pepper 哈希、礼品成员关系和礼品发布元数据；验证码一次性且短时有效。标签本身只含 HTTPS URL，不采集 NFC 芯片 UID。

每件礼品只能有一位拥有者及最多两位受邀只读者。未知邮箱不会收到相册标题、照片或其他元数据。R2 桶不公开；客户端仅在授权后拿到短期上传或读取 URL。

拥有者永久停用礼品时，访问名单和共享快照会立即撤销；媒体删除若临时失败，会由受保护的服务端维护任务重试。请通过 `support@onetapreality.com` 联系隐私支持。
