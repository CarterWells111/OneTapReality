# 隐私说明（Alpha）

生效日期：2026-07-28。适用于 OneTapReality｜一触如初的 Alpha 内部分发。

## 我们收集什么

本地旅行册默认在设备上创建和保存。旅行册生成器只使用标题、城市、日期、照片数量和所选照片顺序，不读取图像像素，也不识别人物、地点或照片内容。

当用户登录并明确发布 NFC 礼品时，服务端会处理邮箱、账号会话和礼品访问名单；该礼品的共享快照和用户选择发布的照片会存放在私有 R2 中，仅用于礼品创建者邀请的查看者访问。

## 数据存放在哪里

- 未发布的照片引用、册子文字与排版数据保存在设备本地的 SQLite 数据库。
- 照片本体保留在系统相册中；只有主动发布的 NFC 礼品所选媒体会上传至私有 R2。
- 本地“删除所有数据”只删除设备本地数据，不会停用已发布礼品；系统相册中的照片不受影响。
- 礼品管理者可在礼品管理流程中停用礼品，停用会删除对应的共享快照与媒体。

## AI 与自动化

当前版本的生成器只使用用户手填标题、城市、日期、照片数量和所选照片顺序，不读取图像像素，也不进行人物或地点识别。

## NFC 与二维码

NFC 礼品卡会打开对应的礼品链接。创建者登录、认领并明确发布后，受邀者才可访问共享内容；礼品链接与访问权限由服务端验证。

## 权限

仅在用户选择照片时请求照片库读取权限。拒绝授权不影响浏览已有内容，但无法在新的旅行册或礼品中选择照片。
