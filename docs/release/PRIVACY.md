# 隐私说明（试用版）

生效日期：2026-07-23。适用于「旅忆」试用版（TestFlight / 内部分发）。

## 我们收集什么

不收集。应用没有账号、没有分析 SDK、没有崩溃上报服务，不向开发者或任何第三方发送用户数据。

## 数据存放在哪里

- 照片引用、册子文字与排版数据保存在设备本地的 SQLite 数据库。
- 照片本体保留在系统相册中，应用只保存本地引用。
- 卸载应用即删除应用内的全部数据（系统相册中的照片不受影响）。

## AI 与自动化

当前版本的「生成旅行册」是本地演示生成器：只使用用户手填的标题、城市、日期和照片数量，不读取图像像素，不做人脸、人物或地点识别，不上传任何内容。将来若接入服务端 AI，将另行征得用户显式同意，且请求中不包含照片二进制、本地 URI、精确位置或生物特征数据（契约见 `src/services/ai/remote-contract.ts`）。

## NFC 与二维码

当前版本不进行真实 NFC 读写。城市钥匙为应用内模拟入口；二维码解析在本地完成，不回传扫描内容。

## 权限

仅请求照片库读取权限（用户选择的照片）。拒绝授权不影响浏览功能。

## 联系方式

隐私问题请联系开发者邮箱（发布前填写正式联系邮箱）。
