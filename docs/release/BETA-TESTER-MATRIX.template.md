# 10 人外部 Beta 测试者矩阵模板

邀请方式：全部使用 TestFlight 邮件邀请；不开放公共链接；不给 App Store Connect 权限。表内只记录测试者代号，真实姓名和邮箱留在获批的发布人私有名单中。

## 固定角色配置

- 卡 A：owner + viewer + editor（3 人）
- 卡 B：owner + viewer + editor（3 人）
- 卡 C：owner + viewer（2 人）
- guest / 本地旅行册专项（2 人）

## 设备覆盖门禁

- [ ] 至少 5 种 iPhone 代际。
- [ ] 至少一台旧于 iPhone XS，专门验证 App 内扫描。
- [ ] 覆盖最低可取得的受支持 iOS（产品下限 iOS 15.1）。
- [ ] 覆盖上一主版本。
- [ ] 覆盖当前稳定版本。
- [ ] iPhone XS 或更新机型覆盖后台/锁屏碰卡。

## 邀请节奏

- [ ] Apple Beta App Review 已批准。
- [ ] 候选在内部组完成 smoke。
- [ ] 发布负责人确认未触发任何 stop condition。
- [ ] 一次通知全部 10 人，不分批替换构建。
- [ ] 支持邮箱和 TestFlight 反馈有人值守。
