# 上架前 QA 检查表

在真机（iPhone，Expo Go 或独立构建）上逐项验证。每项记录：设备、系统版本、结果、截图（如有异常）。

## 1. 照片权限最小化

- [ ] 选择照片直接打开 iOS 系统选择器，不先弹出完整照片库权限请求。
- [ ] 保存 PDF 或导出图片时只申请 add-only/write-only；拒绝后应用不崩溃并可继续分享文件。
- [ ] 拒绝照片保存权限后仍可浏览城市页、创建和编辑已有册子。

## 2. 断网

- [ ] 开启飞行模式后冷启动应用，首页、三城页、册子详情均正常。
- [ ] 断网状态下新建、生成、编辑、保存册子全流程可完成。
- [ ] 断网状态下无异常报错弹窗或长时间加载。

## 3. 保存后重启

- [ ] 新建并保存一本册子，完全杀掉应用后重新打开，册子仍在且内容完整。
- [ ] 编辑已有册子并保存，重启后编辑结果保留。
- [ ] 生成后未确认保存的草稿，重启后不出现在首页。

## 4. 删除

- [ ] 删除一本册子后，首页列表即时更新。
- [ ] 删除后重启应用，被删除的册子不再出现。
- [ ] 删除全部册子后，首页空状态展示正常。

## 5. 城市浏览

- [ ] 杭州、上海、深圳三个城市页均可打开，文案与配色正确。
- [ ] 城市入口可打开对应城市内容并可返回。
- [ ] 城市页在无任何已保存册子时也能正常浏览。

## 6. NFC 礼品（原生构建，staging）

- [ ] `IOS-STG-001`、`IOS-STG-002`、`IOS-STG-003` 写入 staging 礼品 URL 后均能准确读回，并由 iPhone 锁屏碰卡打开正确 App 路由。
- [ ] 受邀 Alpha 邮箱可请求验证码、认领礼品、发布相册，并以受邀只读身份查看。
- [ ] 非 `ALPHA_ALLOWED_EMAILS` 邮箱收到 `beta_invite_required`，且不发送验证码。
- [ ] 礼品管理者停用礼品后，已发布共享媒体不可再读取，私有 R2 对象已删除。
- [ ] `GIFT_SHARING_ENABLED=false` 时，礼品读取、认领、发布和新验证码均返回暂停提示；管理员仍可停用受影响礼品。

> 当前产品只支持并验收 iPhone / iOS。Android 不在当前及可预见产品计划内，本清单不包含 Android 构建、App Links 或真机验收。

## 7. 事实核对（与上架材料一致）

- [ ] 抓包或代码走查确认：本地旅行册不会自动上传；只有明确发布 NFC 礼品时才上传共享快照和照片。
- [ ] 确认生成文案来自本地 `DemoDraftGenerator`，无模型调用。
- [ ] 确认原生构建中的真实 NFC 与邮箱/R2 礼品功能均按隐私说明工作。

## 8. 外部 Beta 1.1.2

- [ ] 退出登录后可以免登录创建、编辑、删除和 PDF 导出；回收站恢复仍可用。
- [ ] guest、账号 A 和账号 B 的本地旅行册彼此隔离，首次登录不会静默迁移 guest 数据。
- [ ] 首次登录明确提供“继续使用 guest 库”和“迁移到当前账号”，迁移失败后 guest 数据与文件完整保留。
- [ ] 登录仅在认领、发布、邀请、协作、礼品管理等云端动作发生时要求。
- [ ] 首页“扫描礼品”只读取当前环境的 HTTPS NDEF 礼品 URL；外域、query/hash、非 URL NDEF 均拒绝。
- [ ] 旧于 iPhone XS 的设备通过 App 内扫描进入礼品；iPhone XS 及更新设备验证锁屏碰卡。
- [ ] owner、viewer、editor 的读取、发布、编辑、移除与退出边界正确。
- [ ] 举报后立即对举报者隐藏；屏蔽后移除关系且双方不能再次邀请；受邀成员可以主动退出。
- [ ] “删除本机旅行册”和“永久删除账号及云端数据”是两个独立入口，说明与实际范围一致。
- [ ] 永久删除账号及云端数据会立即撤销全部会话，返回回执与 24 小时最迟完成时间，并保留独立 guest 库。
- [ ] 反馈入口打开 `support@onetapreality.com` 或说明 TestFlight 截图反馈，不把本机保存称为“已提交”。
- [ ] 按 [外部 Beta 放行清单](./EXTERNAL-BETA-1.1.2.md) 和 [测试者矩阵](./BETA-TESTER-MATRIX.template.md) 记录结果。
