# 上架前 QA 检查表

在真机（iPhone，Expo Go 或独立构建）上逐项验证。每项记录：设备、系统版本、结果、截图（如有异常）。

## 1. 拒绝照片权限

- [ ] 首次进入选照片流程时拒绝照片权限，应用不崩溃，给出可理解的提示。
- [ ] 拒绝权限后仍可浏览三城内容页和已保存的册子。
- [ ] 到系统设置重新授权后，选照片流程恢复正常。

## 2. 断网

- [ ] 开启飞行模式后冷启动应用，首页、三城页、册子详情均正常。
- [ ] 断网状态下新建、生成、编辑、保存册子全流程可完成。
- [ ] 断网状态下无异常报错弹窗或长时间加载。

## 3. 保存后重启

- [ ] 新建并保存一本册子，完全杀掉应用后重新打开，册子仍在且内容完整。
- [ ] 编辑已有册子并保存，重启后编辑结果保留。
- [ ] 生成后未确认保存的草稿，重启后不出现在首页。

## 4. 删除

- [ ] 删除一本册子后，首页列表即时更新。
- [ ] 删除后重启应用，被删除的册子不再出现。
- [ ] 删除全部册子后，首页空状态展示正常。

## 5. 三城浏览

- [ ] 杭州、上海、深圳三个城市页均可打开，文案与配色正确。
- [ ] 模拟 NFC 入口（nfc-demo）可打开对应城市的演示页并可返回。
- [ ] 城市页在无任何已保存册子时也能正常浏览。

## 6. 事实核对（与上架材料一致）

- [ ] 抓包或代码走查确认：核心流程无业务网络请求。
- [ ] 确认生成文案来自本地 `DemoDraftGenerator`，无模型调用。
- [ ] 确认不存在真实 NFC 读写调用。
