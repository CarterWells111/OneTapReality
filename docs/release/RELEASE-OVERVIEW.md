# 上架试用说明（TestFlight / 内部分发）

## 应用是什么

OneTapReality｜一触如初是一款本地优先的旅行纪念册应用。用户挑选照片、手填标题与日期，应用生成可编辑的旅行册；用户也可以在原生构建中明确发布 NFC 礼品共享相册。

## 试用者必须知道的三件事

1. **本地旅行册默认保存在设备。** 照片引用、文字和排版数据存放于设备本地；登录本身不会上传旅行册或照片。
2. **没有真实 AI。** 「生成旅行册」由内置的本地演示生成器（`DemoDraftGenerator`）完成，它只使用用户手填的标题、城市、日期和照片数量，不读取图像像素，不识别人物或地点，不调用任何模型服务。
3. **NFC 礼品共享是可选功能。** 用户通过邮箱验证码登录后，可由礼品管理者明确发布共享相册。只有在发布时，所选照片和共享快照会上传到私有媒体存储，且仅限已授权礼品成员读取；礼品可被管理者永久停用并删除共享内容。

## 权限使用

| 权限 | 用途 | 拒绝后的行为 |
| --- | --- | --- |
| 照片库（读取所选照片） | 选择要放进纪念册的照片 | 仍可浏览三城内容与已保存册子，无法新建带照片的册子 |

应用不请求定位、麦克风、相机、通讯录或通知权限。

## 网络说明

本地旅行册创建、编辑和保存可离线完成。账号登录、礼品认领、共享发布和已发布礼品的读取需要网络；它们不会自动上传任何本地旅行册。

## 审核相关

提交与审核结果由 Apple 独立决定。本文档只描述当前版本的真实行为，不构成对审核通过与否的任何承诺。
