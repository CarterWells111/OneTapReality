# 上架试用说明（TestFlight / 内部分发）

## 应用是什么

「旅忆」是一款本地优先的旅行纪念册应用。用户挑选照片、手填标题与日期，应用生成可编辑的方形旅行册，并可浏览杭州、上海、深圳三座首发城市的内容页。

## 试用者必须知道的三件事

1. **照片仅保存在本机。** 所有照片、文字和排版数据存放于设备本地的 SQLite 数据库与文件系统，应用不上传任何内容，也没有账号体系。
2. **没有真实 AI。** 「生成旅行册」由内置的本地演示生成器（`DemoDraftGenerator`）完成，它只使用用户手填的标题、城市、日期和照片数量，不读取图像像素，不识别人物或地点，不调用任何模型服务。
3. **没有真实 NFC。** 「城市记忆钥匙」为模拟入口，仅在应用内跳转演示页面，不进行任何 NFC 读写。

## 权限使用

| 权限 | 用途 | 拒绝后的行为 |
| --- | --- | --- |
| 照片库（读取所选照片） | 选择要放进纪念册的照片 | 仍可浏览三城内容与已保存册子，无法新建带照片的册子 |

应用不请求定位、麦克风、相机、通讯录或通知权限。

## 网络说明

应用核心功能完全离线可用。除 Expo 运行时的基础能力外，应用自身不发起业务网络请求。
