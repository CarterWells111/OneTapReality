# 相册详情页只读页面预览设计

## 目标

在相册详情页增加“页面预览”入口，让用户在进入画布编辑前查看整册页面缩略图。总览复用编辑器“页面管理”的视觉和画布渲染，但不能新增、删除、多选或拖动页面。

## 范围

- 已保存的普通相册和内置示例相册都显示“页面预览”按钮。
- 点击按钮打开全屏页面缩略图总览，标题显示“页面预览”和当前总页数。
- 总览采用与页面管理相同的双列缩略图、页码标签和 `CanvasPage` 只读渲染。
- 点击任意缩略图或其“打开”操作后关闭总览，并将详情页阅读器切换至所选页面。
- 预览模式不显示添加、删除、取消选择或批量操作，不产生选择状态，也不注册长按拖动排序。
- 不改变“编辑相册”“分享相册”“绑定到礼品”以及标题栏现有操作。

## 组件设计

扩展 `PageManagerSheet`，增加明确的只读 `mode="preview"` 模式；默认仍为现有 `mode="manage"`，避免改变编辑器调用方。两种模式共用缩略图尺寸、画布比例、网格布局和页面打开回调。

管理模式保留现有 `onChange`、选择、删除、新增和拖动。预览模式不要求 `onChange`，不会创建任何变更手势或管理工具栏，并使用独立的标题、说明和无障碍标签。模式分支应位于交互边界，而不是仅用视觉隐藏来禁用编辑。

`MemoryDetailScreen` 持有总览开关状态。用户选择页面时，详情页更新一个预览跳转游标，并把它传给 `PageReader`。`PageReader` 已支持 `initialPageId` 与 `fallbackIndex` 变化后的恢复，因此不新增路由或持久化字段。

## 交互与无障碍

- 入口按钮文字和无障碍名称均为“页面预览”。
- 弹窗关闭按钮的无障碍名称为“关闭页面预览”。
- 每个页面缩略图是按钮，名称为“打开第 N 页”；点击整个缩略图即可打开，不要求点击较小的文字区域。
- 预览说明明确提示“点击页面即可打开”，不出现拖动、多选或删除提示。
- 关闭弹窗但未选页时，详情阅读器保持原页。

## 数据与安全

页面数据直接读取当前内存中的 `memory.pages`，只使用本地 `CanvasPage` 渲染。该功能不写数据库、不创建恢复草稿、不上传照片、不新增依赖、网络请求、分析、支付、第三方服务或客户端秘密。

## 测试

- `PageManagerSheet`：验证预览模式标题和提示；验证管理控件不存在；验证点击页面只调用跳转和关闭，不调用变更回调。
- `MemoryDetailScreen`：验证普通相册与示例相册显示入口；验证打开总览后选择第二页会关闭总览并让 `PageReader` 接收第二页游标。
- 现有页面管理测试继续验证默认管理模式的新增、删除、选择和拖动行为不变。
