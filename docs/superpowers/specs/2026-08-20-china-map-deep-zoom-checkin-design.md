# 中国地图深度缩放、边缘留白与全产品城市打卡设计

## 目标

让用户能把中国地图放大到足以稳定点击每个现有产品城市的圆点，把边缘城市拖到屏幕中央，并让全部 36 个现有产品城市复用同一城市打卡和相册记录流程。

## 交互设计

- 全屏地图支持 1×–6× 缩放。双指缩放继续跟随焦点；双击按 1× → 2× → 4× → 6× → 1× 循环。
- 圆点、文字和 44pt 点击区域维持固定屏幕尺寸，不随缩放放大。
- 平移范围在地图内容边界之外加入视口级留白。最大缩放时，主体最外侧的现有产品城市也能移动到中央 72% × 64% 标签区域，同时地图仍不能无限拖走。
- 标签继续在手势结束后稳定更新；逐帧路径不更新 React 状态、不调用 `runOnJS`。

## 城市打卡

- 全部 36 个现有产品城市点击圆点后直接打开既有 `CityCheckinModal`。
- 全部城市复用既有弹窗流程，并显示弹窗现有的本地中国地图、城市标题与口号，以及无 spots 时的 `0 / 0` 默认视觉。
- 搜索城市并定位后，点击圆点的行为与直接浏览地图一致。
- 341 个地级行政区文字仍不可点击、不可进入无障碍焦点，也不扩展为产品城市。

## 代码边界

- 将最大缩放和拖动留白定义为地图工作区内部常量，并让捏合、双击、边界计算和测试共用。
- 扩展现有打卡图片解析逻辑，使任意 `City` 都能获得专属或默认本地图片；不改变 `CityMapProps`、路由、数据库或城市注册表。
- 不新增依赖、网络请求、地图 SDK、定位、分析、支付、第三方服务或客户端秘密。

## 测试与验收

- 边界函数允许 6×，拒绝超出范围的缩放，并证明边缘产品城市能移动到视口中央。
- 双指与双击缩放均不超过 6×；双击按既定层级循环。
- 最大缩放下圆点和点击区域保持固定尺寸，平移仍受扩展边界限制。
- 36 个产品城市点击均打开打卡弹窗，并显示弹窗现有本地中国地图、城市标题/口号与无 spots 时的 `0 / 0` 默认视觉。
- 现有地级背景标签仍不可点击，现有相册保存、弹窗关闭、详情跳转和 VoiceOver 不回归。
- 完成后运行 `npm run lint`、`npm run typecheck`、`npm run test:ci` 和 `npm run build:server`。
