# 半本书式旅行册草稿编辑器设计

## 目标

把“确认草稿”从页面摘要列表改为可直接编辑的单页旅行册，让用户看到接近实体册翻阅的 3:4 竖版纸张，同时保留现有 Canvas JSON、本地 SQLite 和 Expo Go 技术边界。

## 页面结构

确认页顶部只展示旅行册名称、城市、日期、当前页码与页面管理入口；重新生成和丢弃保留为明确操作，不再显示编辑铅笔。中部为单张纸页，底部依次为页码指示、分类贴纸托盘、上下文编辑工具、自动保存状态和固定“保留草稿”按钮。

第一页按实体册右页处理。奇数页把书脊阴影放在左侧，右侧保留外圆角；偶数页相反。纸张比例固定为 3:4，但内部元素继续使用独立的 0–1 横纵坐标和宽高，所以旧方形数据无需迁移，只会在新矩形纸页上按相对位置重排。

## 翻页与元素编辑

页面容器负责横向翻页手势。拖动时页面跟手横移，按位移比例增加轻微 `rotateY`、透视和阴影；结束时若横向位移超过页面宽度 22%，或横向速度超过 650px/s，则进入相邻页，否则弹回。方向不合法或位于首尾页时始终回弹。

未选中的元素只参与命中测试，不捕获移动；双击元素才进入选择状态。选中元素后，只有从元素内部开始的拖动、缩放和旋转会更新该元素，书页空白区域仍交给翻页手势。选择状态显示描边及“完成”按钮；成功翻页或点击完成都会清除选择。新建文字或贴纸后自动选中，避免用户再次双击。

## 工具与页面管理

`BookCanvasEditor` 是受控组件：父级提供页面、当前页、选择状态策略和保存回调。草稿确认页把每次稳定编辑送入自动保存队列；已保存旅行册编辑页继续在本地维护副本，点击显式保存时写入。

页面管理使用紧凑弹层，提供选择本地照片、添加页面、删除页面、前移和后移；只有一页时禁用删除。贴纸元数据分组如下，并始终提供“全部”：

- 情感：爱心、闪光、信件
- 旅行：相机、行李、地图、地点、票根
- 日常：咖啡
- 自然：花朵、太阳、月亮

文字元素选中时显示文字、字体和颜色工具；任何元素选中时显示前移、后移、复制、删除和完成。分类贴纸托盘不因选择状态隐藏。

## 自动保存

草稿新增不刷新列表的页面持久化方法，内部复用 `updateMemoryPages`。自动保存控制器保存最新页面快照，并保证任意时刻最多一个写入：

1. 没有写入时立即保存最新快照。
2. 写入期间发生变化时只保留最新待写快照。
3. 当前写入完成后继续写最新待写快照，跳过已被覆盖的中间状态。
4. 写入失败时保留失败快照和内存中的最新页面，显示“保存失败·重试”。
5. 重试优先保存当前最新快照，不恢复旧页面。

拖动、缩放和旋转在手势结束时请求保存；添加、删除、复制、换层和页面管理立即请求保存；文字输入以 400ms debounce 合并。最终“保留草稿”等待队列空闲，若仍有失败快照则拒绝确认。重新生成和丢弃先使编辑生命周期失效，再串行执行仓储操作，允许明确覆盖或删除失败快照。

## 测试边界

纯函数测试覆盖翻页判定、矩形坐标变换、贴纸分类和串行合并队列；组件测试覆盖双击选择、空白翻页、选中元素手势隔离、页面管理及草稿确认等待。最后运行 lint、typecheck 和全量测试，并在 Expo Go 真机验证手势、键盘和重启持久化。
