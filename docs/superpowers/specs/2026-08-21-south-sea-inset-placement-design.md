# 南海附图左下布局设计

## 背景

当前生成器把南海附图固定在地图画布右下角。台湾同样位于主体投影的右下区域，因此附图外框和内容会覆盖台湾。主体地图、城市坐标及视口变换本身不需要调整。

## 设计

保持南海附图现有 `132 × 172` 尺寸及底部 `12` 的边距，将其水平位置从右侧改为左侧 `16`。以当前 `1000 × 845` 主图 `viewBox` 为例，附图外框为 `{ x: 16, y: 661, width: 132, height: 172 }`。

位置只在离线地图生成器中定义，生成的 `chinaSouthSeaInset.frame` 继续由概览卡和全屏地图共同消费。运行时组件不增加位置分支，也不修改主体大小、投影、缩放和平移逻辑。

## 安全校验

生成器在输出数据前执行以下校验：

1. 附图外框完整位于主图 `viewBox` 内。
2. 根据生成后的 34 个省级 SVG 路径包围盒，确认附图外框不与任何省级区域相交；该规则同时保护台湾和其他边缘区域。
3. 保留已有的南海附图非空、省级区域数量和确定性生成校验。

若未来投影、画布尺寸或省界数据变化导致左下区域不再安全，生成脚本应直接失败，而不是生成会遮挡主体的地图。

## 测试

先扩展生成数据测试并确认旧的右下布局无法满足新断言，再修改生成器和重新生成数据。测试覆盖：

- 附图具有左侧 `16`、底部 `12` 的预期边距。
- 附图完整落在 `viewBox` 内。
- 附图外框与全部 34 个省级路径包围盒均不相交，包括台湾。
- 重新运行生成器得到的文件保持确定性。

实现完成后运行 `npm run lint`、`npm run typecheck`、`npm run test:ci` 和 `npm run build:server`。

## 范围边界

本次不改变城市标签、城市点击与相册记录、地图最大缩放、边缘留白、无障碍行为、路由、数据库或公共属性接口；不新增依赖、联网数据、地图 SDK、分析或第三方服务。
