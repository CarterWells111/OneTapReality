# 书页空白点击取消组件选中

## 目标

在 `BookCanvasEditor` 中，组件处于选中状态时，用户轻点书页内部且没有组件覆盖的空白区域，立即退出组件编辑状态。

## 交互边界

- 只响应书页内部空白区域的轻点。
- 点击组件内部不取消选中，组件仍需双击才会被选中。
- 点击书页外的工具栏、贴纸栏、页码和页面管理区域不触发该行为。
- 横向滑动仍用于翻页；空白轻点不能干扰跟手位移或翻页阈值判断。
- 取消选中只更新编辑器 UI 状态，不修改页面数据，也不触发保存。

## 实现设计

由 `CanvasPage` 提供可选的 `onPressBlank` 回调，并在书页底层处理点击。每个交互式
`CanvasElement` 继续作为独立点击目标，阻止该次点击落到书页底层。`BookCanvasEditor`
将该回调绑定为清空 `selectedElementId`。

该方案不使用点击坐标与元素矩形手工碰撞检测，因此不会因组件旋转、缩放或层级变化产生
额外边界误判，也不改变现有 Gesture Handler 与 Reanimated 手势结构。

## 测试

- 双击组件后出现选中工具。
- 点击 `album-canvas` 空白区域后选中工具消失。
- 点击已选中组件内部不会取消选中。
- 空白取消选中不会调用 `onPagesChange`。

## 范围外

不改变组件双击、拖动、缩放、旋转、翻页、自动保存、SQLite 或 Canvas JSON schema。
