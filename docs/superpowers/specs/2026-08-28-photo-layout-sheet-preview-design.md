# 照片布局弹层已选图片与即时预览设计

## 目标

让用户在新建照片页面或再次调整任意页面的照片与模板时，始终能先确认已选照片，再查看所选模板应用到这些照片后的完整页面效果。

## 信息顺序

弹层滚动区固定使用以下顺序：

1. “已选择图片”标题；
2. 已选照片缩略图；
3. “重新选择照片”按钮；
4. 保存照片进度提示（仅暂存进行中显示）；
5. 适用于当前照片数量的模板选择；
6. “布局效果预览”及 3:4 页面预览。

零张照片时保留“请先选择照片”，确认按钮禁用。缩略图区域在零张照片时不渲染空标题，避免形成无内容分区。

## 即时预览

- 1–3 张照片且已选择模板时，使用 `createPhotoTemplateLayout` 生成预览布局。
- 1–3 张照片尚未选择模板时，使用 `createPhotoLayout` 显示自动自由排版预览，用户仍可继续选择任一模板。
- 4–12 张照片继续使用 `createPhotoLayout`，在限制提示下显示相同的较大预览。
- 模板选择仅更新弹层内的本地 `selection` 状态，因此预览立即切换，但页面数据直到用户确认后才改变。
- 预览复用持久化布局的弧度旋转值，以 `rad` 渲染，确保与正式画布方向一致。

## 组件边界

变更集中在 `PhotoLayoutSheet`：它根据 `photoUris` 和当前模板选择计算预览布局，渲染已选照片与预览照片。`PhotoTemplatePicker`、`BookCanvasEditor`、页面保存事务及仓储层接口保持不变。

为预览容器和预览图片提供稳定的可访问标签及测试 ID，使测试能验证内容顺序、照片 URI、模板几何和选择后的即时更新，而不依赖视觉截图。

## 保存与错误行为

重新选择照片继续沿用现有暂存、回滚和确认提交逻辑。取消弹层不改变页面；暂存失败保留原有已选照片和预览；暂存进行中禁用重新选择与确认，但仍允许取消。

## 测试

- 编辑模式显示“已选择图片”，并在重新选择按钮之前渲染传入照片缩略图。
- 初始模板对应的 3:4 效果预览包含相同照片 URI 和正确布局。
- 点击另一模板后，预览几何和旋转立即变化，确认仍返回新模板 ID。
- 无模板选择时显示自动自由排版预览。
- 4 张以上继续显示限制提示和自由排版预览。
- 零张照片不显示空的已选图片区，确认保持禁用。

## 范围边界

不新增依赖、网络请求、数据库字段、远端契约、分析、支付、第三方服务或客户端秘密；不修改模板数量、照片数量上限、页面保存边界或共享发布行为。
