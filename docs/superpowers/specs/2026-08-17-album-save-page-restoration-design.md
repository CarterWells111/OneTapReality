# 相册保存后恢复编辑页设计

## 目标

用户在任意页面完成编辑并保存后，退出编辑器进入完整相册预览，预览直接显示刚刚编辑的页面，而不是封面。本地相册、礼品 owner 和已激活 editor 保持同一行为；viewer 仍只读。

## 状态与数据流

- `BookCanvasEditor` 以页面稳定 ID 向父组件报告当前编辑页，同时保留当前索引用于页面删除后的回退。
- 本地保存成功后，把页面 ID 和回退索引随详情路由传递；详情页将其交给 `PageReader`。
- 共享发布成功后重新读取服务端最新版本，但不再回到封面；读取完成后按保存前页面 ID 打开完整预览。
- `PageReader` 在 pages 或目标变化时按 ID 查找页面。目标不存在时把回退索引限制在最新页数范围内；没有目标时维持现有从封面打开的行为。

## 错误与权限

- 本地保存或共享发布失败时不退出编辑器、不改变当前页，并继续显示现有错误提示。
- 403、409 和成员撤权语义保持不变，不允许通过恢复页状态绕过共享权限。
- 页面定位信息只存在于客户端导航或组件状态，不写入相册数据、云端快照或账号存储。

## 测试

- 编辑器翻到非封面页后能向外报告该页面 ID 与索引。
- 本地保存成功后详情阅读器打开对应页面；保存失败不导航。
- owner/editor 发布成功并重新加载后保持完整预览且显示对应页面，不回封面。
- 页面被删除或新版本缺少目标 ID 时回退到最近有效索引。
- viewer 不出现编辑或保存入口。
