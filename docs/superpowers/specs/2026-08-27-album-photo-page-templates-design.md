# 相册照片分页与模板设计

**日期：** 2026-08-27  
**状态：** 已确认，待实施计划  
**范围：** 新建相册草稿、相册内新增页面、已创建页面的照片布局修改

## 目标

让用户在创建相册草稿或新增页面时先选择照片，再选择适合照片数量的模板。产品提供 5 个视觉套系，每套包含 1 张、2 张和 3 张照片版本，共 15 个模板。创建草稿时既能快速配置整册，也能逐页精调；创建完成后仍可修改任意页面的照片数量和模板。

参考图只用于理解模板选择器的信息密度和布局表达。实现不复制参考应用素材、文案或品牌元素；模板全部由本地归一化坐标定义。

## 范围约束

- 所有照片、模板定义、预览和分配状态默认保存在本地。
- 不新增网络请求、第三方服务、支付、分析、客户端密钥或新的依赖。
- 不修改 SQLite 表结构。新增模板标识保存在既有页面 `layout` JSON 中。
- 保持现有账号隔离、照片先持久化后写入画布、恢复草稿和显式保存边界。
- 继续支持单页最多 12 张照片。模板只适用于 1–3 张；4–12 张使用现有自由排版。

## 用户流程

### 创建相册草稿

1. 用户填写旅行信息和封面。
2. 用户从系统照片库选择全部照片。
3. 页面进入“分配照片”阶段，默认选中“一起配置”。
4. 系统按照片原顺序均衡分配，默认内容页数为 `ceil(photoCount / 3)`，使初始页面都能使用模板。
5. 用户可以调整内容页数、选择分配建议，并在页面缩略预览中查看每页照片数量。
6. 用户可以切换到“逐页配置”，为每页选择具体照片、照片数量和模板。切换模式共享同一份分配状态，不重置已完成操作。
7. 用户选择一个模板套系后，可“应用到全部页面”。系统根据各页照片数量自动选择该套系的单图、双图或三图版本。
8. 用户可以覆盖任意页面的模板，然后确认创建草稿并进入现有画布编辑器。

封面和尾页由系统生成，不计入用户配置的内容页数。

### 新增单一页面

1. 用户在页面管理中点击“添加页面”。
2. 系统先打开照片选择器，不立即插入空白页。
3. 用户选择 1–3 张照片时，系统展示与该数量匹配的 5 个模板。
4. 用户选择 4–12 张照片时，系统提示“模板支持 3 张及以内照片；仍可继续创建，并在画布中自行排版”，随后展示自由排版预览。
5. 用户确认后，照片先复制到当前账号与相册的应用 Documents 目录。全部复制成功后才创建页面。
6. 用户取消照片选择、取消模板面板或照片复制失败时，不创建页面。

### 创建后的修改

- 编辑器增加“照片布局”入口，服务当前内容页。
- 用户可替换该页照片、改变照片数量或重新选择模板。
- 1–3 张照片显示对应的 5 个模板；4–12 张显示自由排版状态。
- 模板变更只调整图片元素的位置、尺寸与旋转，不删除或重排文字、贴纸、相框、背景和其他非图片元素。
- 用户手动移动、缩放或旋转图片后，页面清除模板标识并转为“自由排版”。
- 添加或删除图片后同样清除旧模板标识，直到用户重新套用一个匹配模板。

## 交互方案

采用“混合式”配置：默认整册快速配置，同时提供逐页精调。

### 一起配置

- 显示照片总数、内容页数步进器、分配建议和页面缩略预览。
- 内容页数最少为 1，最多为照片数量，且任何页面不得为空。
- 默认使用不超过 3 张/页的均衡分配。
- 用户主动减少页数而使某页超过 3 张时允许继续；该页标为“自由排版”。
- 选择套系后可应用到所有 1–3 图内容页；超过 3 张的页面保持自由排版，并在完成后提示被跳过的页码。

### 逐页配置

- 显示当前页、总页数、剩余照片和照片缩略图。
- 用户选择该页照片后只显示适用模板。
- 保存当前页后进入下一页；可返回修改前一页。
- 从“一起配置”切换而来时沿用现有分配；返回“一起配置”也不重新均衡，除非用户主动选择新的分配建议或改变页数。

## 15 个模板

模板按 5 个套系组织，每套包含 1、2、3 图三个版本：

1. **经典留白：** 单图大留白；双图上下均衡；三图上大下双。
2. **杂志侧栏：** 单图偏置留侧栏；双图左主右辅；三图左主右双。
3. **横向叙事：** 单张横幅；双图上下错落；三图横向连续。
4. **手账错落：** 轻微旋转的单图、双图和三图拼贴。
5. **竖向切片：** 单列、双列和三列纵向图片。

模板注册表为每个模板保存：

- 稳定模板 ID；
- 套系 ID；
- 照片数量；
- 中文显示名；
- 图片槽位的归一化 `x`、`y`、`width`、`height` 和 `rotation`。

所有槽位必须位于 3:4 页面边界内。模板预览与实际画布使用同一注册表，防止缩略图和最终结果不一致。

## 数据模型

### 页面模板标识

`CanvasLayout` 增加可选 `photoTemplateId`。旧页面没有该字段时视为自由排版并继续正常读取。

模板 ID 表达完整数量版本，例如：

- `classic-1`
- `classic-2`
- `classic-3`

批量应用保存套系选择，但实际写入各页的是与照片数量匹配的完整模板 ID。

### 草稿页面计划

`MemoryDraftInput` 增加可选页面计划，每个计划包含有序照片 URI 列表和可选模板 ID。新建草稿页面提交计划；`DemoDraftGenerator` 根据计划生成内容页 layout。缺少页面计划的旧调用继续沿用原有一图一页行为，保证兼容现有测试和潜在调用方。

页面计划只用于本地生成，不上传照片 URI，也不改变远程 AI 契约的最小化字段。

## 模板应用规则

套用模板时：

1. 读取当前页按层级和现有数组顺序排列的图片元素。
2. 校验图片数量等于模板照片数量。
3. 只把模板槽位的几何字段写入对应图片元素。
4. 保留图片元素 ID、URI 和既有层级；保留所有非图片元素及 layout 元数据。
5. 写入 `photoTemplateId`。

手动修改图片几何、添加图片或删除图片时清除 `photoTemplateId`。修改文字、贴纸、相框、背景、封面元数据或非图片层级不清除模板标识。

## 组件边界

- **模板注册表：** 只定义 15 个模板并提供按数量、套系和 ID 查询的纯函数。
- **照片分页模型：** 负责均衡分配、页数调整、逐页照片更新、空页校验和批量套系解析。
- **模板选择器：** 共享展示 5 个匹配模板，并返回选择，不直接持久化数据。
- **草稿分配界面：** 管理“一起配置”和“逐页配置”的表现状态，提交页面计划。
- **编辑器照片布局面板：** 管理当前页照片选择和模板选择；确认后通过现有编辑事务更新页面。
- **页面管理：** 只发出新增页面请求；照片选择、持久化和页面创建由编辑器拥有，避免页面管理组件承担文件生命周期。

## 状态与数据流

### 草稿

`系统照片选择器 → 草稿分配状态 → 页面计划 → DemoDraftGenerator → StoryPage.layout → 本地照片持久化与 SQLite 草稿`

### 新增或修改页面

`照片布局入口 → 系统照片选择器 → 照片持久化 → 模板选择 → 编辑器页面事务 → 恢复草稿/显式保存`

新增照片只有在持久化成功后才能进入画布状态。模板预览可使用选择器临时 URI，但确认操作必须等待规范化本地 URI。

## 错误处理

- 照片权限被拒绝：显示现有权限提示，不修改当前分配或页面。
- 用户取消系统选择器：保留原状态；新增页面流程不创建页面。
- 用户取消模板面板：回滚面板内未确认变更。
- 照片复制失败：显示既有 iCloud、权限和存储空间提示，不写入临时 URI，不创建或修改页面。
- 页面照片为 0：禁用确认，允许取消恢复面板打开前状态。
- 整册套系跳过自由排版页：其他匹配页面正常完成，并提示跳过的页码。
- 模板 ID 未知或照片数量不匹配：保持当前几何并回退为自由排版，不导致页面读取失败。

## 可访问性

- 模板选项暴露“套系名 + 单图/双图/三图”标签、按钮角色和选中状态。
- 模式切换、页数步进器、页面缩略图与确认按钮具备明确中文标签。
- 触控目标符合 iPhone 操作尺寸；选中状态同时使用边框、勾选和文字，不只依赖颜色。
- 错误与跳过提示为可读取文本，不依赖短暂动画。

## 测试策略

严格使用测试先行：先写测试并确认因缺少目标行为而失败，再实现最小代码。

### 纯函数

- 模板注册表恰好包含 15 个唯一模板，每个照片数量恰好 5 个。
- 每个槽位坐标、尺寸和旋转均合法且位于页面范围内。
- 默认均衡分配、页数增减、照片顺序保持和空页拒绝。
- 套系批量应用正确匹配数量，并跳过 4–12 图页面。
- 未知模板和数量不匹配安全回退自由排版。

### 草稿生成

- 页面计划生成封面、按计划排列的内容页和尾页。
- 每页照片 URI、模板 ID、position 和布局正确。
- 缺少页面计划时保留旧的一图一页行为。

### 编辑行为

- 新增页面必须先选择照片；取消不创建页面。
- 1–3 张只显示对应 5 个模板；4–12 张显示提示并创建自由排版。
- 模板切换保留所有非图片元素和 layout 元数据。
- 手动图片几何变更、添加或删除图片会清除模板 ID。
- 照片复制失败不改变页面状态。

### 完成门禁

- `npm run lint`
- `npm run typecheck`
- `npm run test:ci`
- `npm run build:server`

## 非目标

- 不实现超过 3 张照片的固定模板。
- 不自动分析照片像素、人物、地点、方向或质量。
- 不新增云端模板、素材商店、付费模板或模板下载。
- 不改变封面/尾页的现有职责，也不把它们纳入内容页计数。
- 不在本阶段实现跨页面拖放照片；逐页配置通过照片选择与页面计划完成。
