# 共享相册暂存与发布分离设计

## 目标

Owner 和 editor 在共享相册编辑页中可以先把名称、旅行日期和 Canvas 修改暂存在本次编辑会话，再决定何时向礼品权限者发布新版本。暂存不得产生任何远程副作用；发布继续使用现有权限、媒体上传和版本冲突机制。名称与日期的交互必须复用最新本地相册编辑实现。

## 交互语义

- 第一个按钮命名为“暂存当前修改”。点击后调用 `BookCanvasEditor.prepareSave()`，等待正在进行的变换及样式草稿收敛，并用返回的 `{ pages, cursor }` 更新当前编辑页内存状态。
- 名称使用与本地相册相同的双击标题编辑；日期使用相同的原生日期选择器、最小日期、最大日期与 ISO 转换规则。名称、日期和页面任一变化都令共享会话 dirty。
- 暂存成功后停留在当前页，保留当前名称、日期、页面和游标，保持 dirty 状态，不调用 owner/editor 发布 API，也不上传媒体、增加版本或触发 `onPublished`。
- 第二个按钮保留“保存并发布更新”。点击后同样先准备最新 Canvas 快照，再通过当前角色对应的既有 API 发布。成功后返回共享预览并恢复当前页面游标。
- 没有修改时，“暂存当前修改”是无远程副作用的 no-op；“保存并发布更新”直接返回预览且不创建空版本。
- 暂存不是持久化草稿。用户离开编辑页、关闭应用、登出或切换账号后内容不恢复；存在未发布修改时继续使用当前离开确认。

## 数据流与状态

抽取一个受控 `AlbumMetadataEditor`，封装标题双击编辑、日期选择器和一致的展示样式。本地相册编辑页继续拥有本地 `MetadataDraft`、身份隔离和正式保存事务，只把当前值、disabled 状态与变更回调传入组件。共享编辑页拥有独立的 `{ title, travelDate }` 内存草稿并传入同一组件；复用 UI 与校验，但不共享本地持久化状态。

`SharedAlbumEditor` 将准备快照与远程发布拆成两个内部操作。暂存只更新 `pages`、元数据草稿、活动页游标和 dirty 状态并释放 Canvas 保存锁。发布从当前编辑会话再次获取最终快照，以确保暂存后继续进行的修改也被包含，再把 `title`、`travelDate`、pages 与媒体清单一起送入现有 start/finish publish 流程。

Owner 继续使用 owned-album publish API，editor 继续使用 activated-editor publish API。viewer 不进入编辑路由，但共享预览在发布后展示相同的名称和日期。编辑或发布共享元数据不得修改 owner 本地旅行册。

## 存储与兼容

共享相册表新增 nullable `travel_date`，格式继续为 `YYYY-MM-DD`。迁移不得为历史记录写入伪造日期：已有共享相册保持 `null`，读取时显示“未设置旅行日期”。新礼品首次从本地旅行册发布时携带该册真实 `travelDate`；历史相册的 owner/editor 可以在共享编辑页选择日期并在下一次发布时写入。

共享相册读取结果与发布 payload 增加 `travelDate: string | null`。服务端仅接受 `null` 或现有旅行日期校验允许的 ISO 日期，继续在完成发布事务时和标题、版本一起更新。R2 对象模型不改变。

## 错误与退出

- Canvas 快照准备未完成时显示现有准备失败提示，不改变当前内容，可再次暂存或发布。
- 标题为空时暂存可保留当前输入，但发布必须显示验证错误且不调用远程 API。日期为空仅用于兼容历史共享相册，可继续查看和暂存；用户选择日期后按本地规则校验。
- 暂存不会产生网络错误；暂存后的 dirty 状态确保返回/关闭仍触发放弃确认。
- 发布网络失败保留当前内存快照和 dirty 状态供重试。
- `409 gift_album_version_conflict`、权限撤销及上传失败继续使用既有处理。

## 测试

- 暂存调用 `prepareSave`，更新编辑器页面与游标，但 owner/editor 的 start/finish publish API、上传请求和 `onPublished` 均不调用。
- 暂存同时保留名称与日期草稿；仅修改元数据也会保持 dirty 和退出确认。
- 暂存后继续编辑，再点击发布时只发布最新准备快照，而不是暂存时的旧快照。
- 暂存后的 dirty 状态继续上报给路由退出保护。
- 暂存准备失败可重试；发布失败仍保留暂存内容并可重试。
- 无修改暂存不发布；无修改发布不创建空版本并返回预览。
- Owner/editor 发布 API 分流、媒体稳定引用、真实 Canvas 渲染与 Fabric 可调用形态继续通过现有测试。
- 本地编辑页和共享编辑页都渲染同一个元数据编辑组件；本地保存仍写本地相册，共享发布只写共享版本。
- 迁移保持历史 `travel_date = null`，新首次发布写入本地日期，后续 owner/editor 发布更新名称和日期，viewer 读取发布后的值。

## 范围边界

除 nullable `shared_albums.travel_date` 及对应内部读取/发布契约外，不新增其他数据库模型。不新增本地共享草稿、服务端草稿、自动发布、实时协作、第三方服务、支付或分析。暂存内容只属于当前正在打开的编辑会话。
