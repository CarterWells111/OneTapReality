# OneTapReality 产品介绍与截图轮播设计

## 目标

将用户提供的 `OneTapReality_2（压缩）(1).html` 中的全部产品介绍内容整合到官网营销页。保留既有章节顺序、中文文案、纸质旅行手账风格和每张 App 截图对应的标题与说明；仅将原本分散呈现的 App 截图功能段落重组为一个左右翻页的模块。

## 信息结构

营销页继续保留现有首屏、支持页和隐私政策入口。在首屏后的产品介绍区域中，按原 HTML 的章节顺序呈现品牌故事、功能介绍、团队/素材/视觉展示、合作与愿景等内容。

所有包含 App 截图的功能介绍合并为一个“产品功能”轮播区：

- 每一页对应原页面的一项功能；
- 单页始终包含一张原始 App 截图、原有标题、英文副标题（如原文提供）和完整说明/要点；
- 桌面端采用截图与文字并列的阅读布局；窄屏采用截图在上、文字在下的布局；
- 非截图内容仍按原来的章节与网格样式显示，不并入轮播。

## 交互与可访问性

轮播提供“上一页”和“下一页”按钮、当前页码及总页数。用户可用点击、触摸横向滑动和键盘左右方向键切换；焦点在轮播内时方向键有效。按钮到达首尾时循环到另一端，避免用户误以为内容已消失。

所有截图保留有意义的替代文本；切换仅更新当前页，不自动播放，不引入追踪、远程脚本或第三方组件。启用减少动态效果时，切换取消位移动画但功能不变。

## 资产与边界

从用户提供的自包含 HTML 中提取其现有图片与可用文案，作为随网站发布的本地静态资产。不会新增登录、表单、分析、支付、云端数据、真实 NFC 或任何网络请求；产品能力文案以原资料为准，不扩写为未实现能力。

原资料中关于商店、实体纪念品、真实 NFC 文创、城市花束及相关合作的章节完整保留，但每个章节和轮播页都加入“未来规划 / 概念展示”标记。该标记不改变章节布局、截图、标题或说明的对应关系，只明确它们不是当前已开放的 App 功能或购买入口。

## 测试与验证

先补充静态网站测试，要求产品介绍模块存在、所有原截图条目被收集为轮播页、每页具有截图及关联说明，并且上一页/下一页控制具备可访问标签。测试先失败，再实施最小 HTML/CSS/JS 与资产提取代码使其通过。

完成后构建静态站点、运行网站专项测试，并验证首页、支持页和隐私页在部署后均可访问。
