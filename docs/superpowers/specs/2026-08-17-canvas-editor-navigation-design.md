# 相册编辑导航设计

## 目标

从相册任意阅读页进入编辑时，在同一页开始编辑；保存后回到该页，并避免重复编辑/保存造成详情页在导航栈中叠加。

## 设计

`PageReader` 把已稳定的当前页游标报告给详情页。详情页的两个编辑入口将 `pageId` 和 `pageIndex` 传给编辑路由；编辑页把游标交给 `BookCanvasEditor`，后者按 ID 优先、索引回退的规则初始化当前页。

保存时使用 Expo Router 的 `dismissTo` 返回已有详情页并携带最新游标。若编辑页由深链直接打开且栈中没有详情页，`dismissTo` 自动以详情页替换编辑页，因此不会留下多余路由。

## 验证

- 测试阅读页的编辑入口携带当前页参数。
- 测试编辑器使用传入游标初始化指定页面并安全回退。
- 测试保存调用 `dismissTo` 而非 `replace`，以验证不会叠加详情页。
- 运行 lint、typecheck、完整测试和 Expo Web 生产构建。
