# 草稿创建错误提示修复

- 目标：针对 1.2.0 TestFlight 报告的创建失败提示，把创建草稿各环节的失败对应到安全、可操作的提示，验证成功和失败路径。PR 以远端 main 为基线，只包含本次修复，不包含 1.2.0 的图标或版本更新。
- 范围：本地输入校验、照片与封面导入、页面生成、照片引用、本地保存、本机库状态、保存后刷新和导航；不涉及云端配置或发布。
- 决定：不展示原生异常全文、文件路径、账号或标识；保存后的列表刷新失败保留创建成功语义。
- 完成：错误分类与界面接入、保存后刷新成功语义、导航重试防重复、照片回滚及日志脱敏回归。合并前独立审查另补旧草稿清理日志脱敏、当前 Expo iOS 权限文案/错误码分类，以及保存后路由仍在队列中时的表单锁定。
- 验证：先确认旧行为失败，再实现；独立审查新增的三个边界也均先确认失败。审查修正后，最终 lint、typecheck、test:ci、build:server 和差异检查全部通过：231 个套件/1898 项 Jest 测试、29 项 Node 站点/文档测试。独立复核未发现剩余阻塞问题；测试输出存在非阻塞的 React act 警告。

## 对应提示

照片场景的「第 N 张照片」会替换成失败照片的序号；独立封面显示「封面照片」。未知原生错误也按失败阶段提示，原始异常不直接展示。

| 错误/环节 | 对应提示 |
| --- | --- |
| 标题为空 | 请输入纪念册标题。 |
| 城市无效 | 请选择支持的城市。 |
| 未选择照片 | 请至少选择一张照片。 |
| 本机库准备中 | 本机旅行册仍在准备中，请稍后再试。 |
| 本机库已切换 | 本机旅行册已经切换，请重新打开创建页面后重试。 |
| 本机库迁移中 | 本机旅行册正在迁移，请稍后再试。 |
| 本机库安全操作中 | 本机旅行册正在进行安全操作，请稍后再试。 |
| 导入照片时空间不足 | 设备存储空间不足，无法导入第 N 张照片。请释放空间后重试。 |
| 保存时空间不足 | 设备存储空间不足，无法保存旅行册。请释放空间后重试。 |
| 照片读取/保存权限不足 | 无法读取或保存第 N 张照片。请检查照片访问权限，重启应用后重试。 |
| 本地写入权限不足 | 应用暂时无法写入本机旅行册。请重启应用后重试；若仍失败，请联系支持。 |
| 照片文件缺失 | 第 N 张照片已不可用。请在系统相册中确认照片已下载到本机，再重新选择。 |
| 照片暂时不可读 | 第 N 张照片暂时无法读取。请在系统相册中打开并下载该照片，再重新选择。 |
| 复制后的照片验证失败 | 第 N 张照片未能成功保存。请重新选择该照片后重试。 |
| 本地存储所需文件缺失 | 本机旅行册所需文件暂时无法访问。请重启应用后重试；若仍失败，请联系支持。 |
| 数据库忙/锁定 | 本机旅行册正在被占用，请稍后重试。 |
| 数据库损坏/格式无效 | 本机旅行册数据暂时无法读取。请重启应用；若仍失败，请联系支持，不要卸载应用。 |
| 数据库表/字段不匹配 | 本机旅行册数据结构尚未准备完成。请重启应用并确认已更新到最新版本；若仍失败，请联系支持。 |
| 数据库只读 | 本机旅行册当前无法写入。请重启应用后重试；若仍失败，请联系支持。 |
| 其他照片导入错误 | 导入第 N 张照片时失败。请重新选择该照片后重试；若仍失败，请联系支持。 |
| 页面生成错误 | 生成旅行册页面时失败。请调整页面布局后重试；若仍失败，请联系支持。 |
| 照片引用准备错误 | 准备旅行册照片时失败。请重新选择照片后重试；若仍失败，请联系支持。 |
| 其他本地保存错误 | 保存旅行册草稿时失败。请稍后重试；若仍失败，请联系支持。 |
| 其他创建错误 | 无法创建旅行册草稿，请稍后重试；若仍失败，请联系支持。 |
| 草稿已保存，列表刷新失败 | 草稿已保存，但草稿箱刷新失败。你可以继续编辑，返回首页后再试。 |
| 草稿已保存，打开编辑页失败 | 草稿已保存，但无法打开编辑页。请返回首页，从草稿箱打开。 |
| 照片选择器失败 | 无法选择照片，请重试。 |
| 封面选择器失败 | 无法选择封面图片，请重试。 |

- 自动测试覆盖原生异常模拟、界面提示、未知错误隐私、失败回滚、保存成功后的刷新与导航，以及账号切换保护。

- 未执行任何云端修改、EAS 构建或 TestFlight 上传；已安装的 1.2.0 不会自动获得本地改动。
